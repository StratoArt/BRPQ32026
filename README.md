# Invoice Manager
Frontend GitHub Pages untuk sistem invoice berbasis Google Sheet + Google Apps Script.

Struktur:
- index.html
- css/style.css
- js/app.js

Setup:
1. Deploy Code.gs sebagai Apps Script Web App.
2. Copy URL `/exec`.
3. Isi `API_URL` di `js/app.js`.
4. Upload folder ke GitHub.
5. Aktifkan GitHub Pages.
